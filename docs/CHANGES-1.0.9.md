# Qufu Codex Dashboard 1.0.9

Author / Yazar: alper@qufu.io · MIT · Windows

## English

- Weekly quota defaults to API-equivalent dollars with two decimal places, such as ≈ 500.00$ / 1200.25$. Switch to Token; your choice is remembered.
- Dollar projections use the observed uncached Input, Cache and Output mixture and fixed bundled short-context API prices. Unknown prices/evidence stay unavailable; official quota percentages are unchanged. This is an estimate, not your subscription bill or an official dollar allowance.
- Task/quota chart selectors contain Raw Token and API $, with official percentage additionally available for weekly quota. Remove task-spending warnings and extra CLI/reference/Sol menu choices; retain measured context history and original stored data.
- Auto Follow is enabled once on settings migration and no longer labeled Beta. It follows only verified selections in the session list, keeps manual selection otherwise and remembers later opt-out.
- Settings and Details keep the main window's 300px width while height fits content. Remove the redundant context-source caption.

Windows x64 installer and optional portable executable are available. Historical Linux packages through 1.0.7 remain unchanged. No quota history is deleted.

**Update:** Check for updates → Download and install. Existing consolidated-endpoint installations can update in-app. Older legacy-endpoint installations require manual installation. The installer downloads WebView2 when missing and requires internet for that step.

## Türkçe

- Haftalık kota varsayılan olarak iki ondalık basamaklı API dolar karşılığını gösterir: ≈ 500.00$ / 1200.25$. Token görünümüne geçiş tercihi kaydedilir.
- Dolar tahmini gözlenen cache dışı Input, Cache ve Output dağılımını ve sabit paketlenmiş kısa-context API fiyatlarını kullanır. Eksik fiyat/veri sıfır gösterilmez; resmî kota yüzdeleri değişmez. Bu tahmin abonelik faturası veya resmî dolar kotası değildir.
- Görev/kota grafiklerinde Raw Token ve API $, haftalıkta ayrıca resmî yüzde seçilebilir. Harcama uyarıları ve fazla CLI/referans/Sol seçenekleri kaldırıldı; ölçülen context geçmişi ve kayıtlı özgün veriler korunur.
- Auto Follow ayar göçünde bir kez açılır; Beta etiketi kaldırıldı. Yalnızca doğrulanmış ve listede bulunan seçimi takip eder, aksi hâlde manuel seçimi korur. Sonradan kapatılması hatırlanır.
- Settings ve Details açıldığında genişlik 300 piksel kalır; yükseklik içeriğe uyar. Gereksiz context kaynağı açıklaması kaldırıldı.

Windows x64 kurulumu ve isteğe bağlı taşınabilir dosya sunulur. 1.0.7 ve önceki Linux paketleri korunur. Kota geçmişi silinmez.

**Güncelleme:** Güncellemeleri kontrol et → İndir ve kur. Birleştirilmiş güncelleme adresini kullanan sürümler program içinden güncellenebilir. Eski adrese bağlı sürümler elle kurulmalıdır. Kurucu eksik WebView2'yi internetten indirir.
