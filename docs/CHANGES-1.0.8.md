# Qufu Codex Dashboard 1.0.8

Author / Yazar: alper@qufu.io · MIT · Windows

## English

- Simplify the weekly limit card: remove the inline model-equivalent/assumption suffix. Both quota fraction values now show three decimals, such as ≈ 1.150B / 3.500B Token.
- Keep the approximation marker, learning status and explanatory tooltip. This is a display change; quota calculations and official percentages are unchanged.
- New official packages are Windows-only. Linux downloads through 1.0.7 remain available in historical releases; no existing data or user settings are removed.

Weekly scenario values remain model-normalized estimates, not an official raw-token allowance or API bill. Assumptions and original measurements remain accessible in tooltips and history.

**Update:** Check for updates → Download and install. Signed Windows x64 setup and the optional portable executable are available. Installations using the consolidated updater endpoint can update in-app; legacy-endpoint versions require a manual installation.

## Türkçe

- Haftalık limit satırındaki model eşdeğeri/varsayım eki kaldırıldı. Kota kesrinin her iki değeri üç ondalık basamakla gösterilir: ≈ 1.150B / 3.500B Token.
- Yaklaşık işareti, öğrenme durumu ve açıklayıcı araç ipucu korunur. Kota hesapları ve resmî kullanım yüzdeleri değişmedi.
- Yeni resmî paketler yalnız Windows içindir. 1.0.7 ve önceki Linux indirmeleri korunur; kullanıcı verileri ve ayarları silinmez.

Haftalık senaryo değerleri modele göre normalize edilmiş tahminlerdir; resmî ham token hakkı veya API faturası değildir. Varsayımlar ve özgün ölçümler araç ipuçları ile geçmişte erişilebilir.

**Güncelleme:** Güncellemeleri kontrol et → İndir ve kur. İmzalı Windows x64 kurulumu ve isteğe bağlı taşınabilir dosya sunulur. Birleştirilmiş güncelleme adresini kullanan sürümler uygulama içinden güncellenebilir; eski adrese bağlı sürümler elle kurulmalıdır.
