# Qufu Codex Dashboard 1.1.0

Author / Yazar alper@qufu.io · MIT · Windows

## English

- Weekly Token and API $ estimates now include GPT-6.2 Sol and Astra. GPT-6.2 Sol is the budget reference and retains the previous scale because its Standard rates are identical.
- GPT-6.2 Ultrafast estimates use the tariff in effect when the usage was recorded. The promotional rate is 3× Standard through February 28, 2027. The 6× list rate starts March 1 at midnight Pacific time.
- Windows users can select **Check for updates → Download and install** or download the x64 installer under Assets. A portable executable is also available.

## Türkçe

- Haftalık Token ve API $ tahminleri artık GPT-6.2 Sol ve Astra kullanımını da kapsıyor. Bütçe referansı GPT-6.2 Sol oldu. Standard fiyatları aynı olduğundan hesap ölçeği korundu.
- GPT-6.2 Ultrafast tahminleri kullanımın kaydedildiği tarihteki tarifeyi kullanıyor. Pasifik saatine göre 28 Şubat 2027 sonuna kadar Standard fiyatın 3 katı, 1 Mart gece yarısından itibaren 6 katı uygulanıyor.
- Windows kullanıcıları **Güncellemeleri kontrol et → İndir ve kur** yolunu kullanabilir veya Assets bölümünden x64 kurucuyu indirebilir. Taşınabilir sürüm de mevcut.
