# Qufu Codex Dashboard 1.0.7

Author / Yazar: alper@qufu.io · MIT · Windows & Linux

## English
- Add a weekly Sol 6.1-equivalent analytical view using frozen bundled short-context API price ratios and a single robust median scale.
- Clearly label the GPT-5.4 Standard proxy for the literal Standard codex-auto-review label as an assumption. OpenAI has not confirmed the reviewer's underlying model or subscription accounting.
- Keep strictly known-price-only replay, original raw/reference history and official percentages available in the chart menu.
- Replay historical scenario estimates using only observations through their cutoff; retain insufficient/learning/error states.

This is a modeling scenario, not an official quota formula, fixed raw-token allowance or API bill. Context-length/cache-write details are not available in quota samples. Unknown model/tier intervals remain excluded. Original local records, raw model labels and historical calibrations are preserved; no database migration or historical overwrite is performed.

**Update:** Check for updates → Download and install. Signed in-app updates work from 1.0.4–1.0.6. Windows x64 setup, optional portable executable, and Linux DEB/AppImage are available. Earlier legacy-endpoint versions require manual installation.

## Türkçe
- Haftalık kota için sabit paketlenmiş kısa-context API fiyat oranları ve tek robust medyan ölçeği kullanan Sol 6.1 eşdeğeri analiz görünümü eklendi.
- Standard codex-auto-review etiketi için GPT-5.4 Standard fiyatı yalnızca açıkça belirtilen bir varsayım olarak kullanılır. İnceleyicinin gerçek modeli ve abonelik hesabı OpenAI tarafından doğrulanmış değildir.
- Grafik menüsünde yalnız fiyatı bilinen modellerle tekrar hesaplama, özgün ham/referans geçmişi ve resmî yüzdeler korunur.
- Geçmiş senaryolar yalnız kendi ölçüm anına kadar olan gözlemlerden üretilir; yetersiz veri/öğrenme/hata durumları gösterilir.

Bu bir modelleme senaryosudur; resmî kota formülü, sabit ham token hakkı veya API faturası değildir. Kota örneklerinde context uzunluğu/cache yazma ayrıntıları yoktur. Bilinmeyen model/tarife aralıkları dışarıda bırakılır. Yerel kayıtlar, ham model isimleri ve eski kalibrasyonlar korunur; veritabanı göçü veya geçmişin üzerine yazma yapılmaz.

**Güncelleme:** Güncellemeleri kontrol et → İndir ve kur. 1.0.4–1.0.6 üzerinden imzalı güncelleme desteklenir. Windows x64 kurulumu, isteğe bağlı taşınabilir dosya ve Linux DEB/AppImage paketleri sunulur. Eski güncelleme adresine bağlı sürümler elle kurulmalıdır.
