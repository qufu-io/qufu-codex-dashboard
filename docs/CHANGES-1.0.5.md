# Qufu Codex Dashboard 1.0.5

Author / Yazar: alper@qufu.io · MIT · Windows & Linux

## English
- Show a separate raw-token capacity projection based on the observed N/C/O mix, preserving the fixed uncached-input reference and official percentages.
- Correct quota-change analysis, chronological fit validation and current plan/reset mix boundaries. Learning estimates are explicit; missing or inconsistent data remain unknown.
- Preserve historical calibration data and gaps; distinguish raw projection from reference capacity in history charts.
- Hide the five-hour card for personal Pro, Pro Lite and Pro Max plans. Context capacity remains the selected session's Codex-reported measurement.
- Restore CLI Used as the default task-history metric.

Existing 1.0.4 users: **Check for updates → Download and install** in the application. Windows: use the x64 setup executable. Linux: use the DEB or AppImage. Versions 1.0.3 and earlier require a manual install because their updater used the legacy repository.

Raw capacity depends on usage mix; it is not an official fixed token quota. Local observations cannot prove backend limit changes or perfectly attribute concurrent different-account/remote usage. Existing user data and settings are preserved.

## Türkçe
- Gözlenen N/C/O dağılımına bağlı ayrı ham token kapasitesi tahmini eklendi; sabit cache dışı input referansı ve resmî yüzdeler korundu.
- Kota değişimi analizi, geçmiş pencerelerle doğrulama ve güncel plan/reset dağılımı düzeltildi. Öğrenme tahminleri belirtildi; eksik veya tutarsız veri kesinleştirilmedi.
- Geçmiş kalibrasyon kayıtları ve boşluklar korundu; grafiklerde ham tahmin ile referans kapasite ayrıldı.
- Pro, Pro Lite ve Pro Max hesaplarında 5 saatlik alan gizlendi. Context kapasitesi seçili session'ın Codex ölçümünden gelir.
- Görev grafiğinin varsayılanı yeniden CLI Used oldu.

1.0.4 kullanıcıları: uygulamada **Güncellemeleri kontrol et → İndir ve kur**. Windows için x64 kurulum dosyasını, Linux için DEB veya AppImage paketini kullanın. 1.0.3 ve öncesi eski güncelleme deposunu kullandığından güncel sürüm elle kurulmalıdır.

Ham kapasite kullanım dağılımına bağlıdır; resmî sabit token kotası değildir. Yerel gözlemler backend kota değişimini veya eşzamanlı farklı hesap/uzak cihaz tüketimini kesin belirleyemez. Kullanıcı verileri ve ayarlar korunur.
